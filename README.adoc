= FJH Rig
:toc:
:toclevels: 2

Bench-scale Flash Joule Heating reactor for 1 g flash-graphene production per shot.

== Status

[cols="1,3", options="header"]
|===
| Phase | State

| Specification    | Substantially complete (rev: 14-cap-N170-W8-Wale-Arch4)
| Sourcing         | In progress; major parts identified, some PNs pending
| Build            | Not started
| Commissioning    | Not started
| First shot       | Blocked on: gate driver bench test, sample handling design, diagnostics sourcing
|===

== Quick reference

[cols="1,2", options="header"]
|===
| Parameter | Value

| Bank stored energy   | ~20 kJ (252 mF @ 400 V, 14 caps parallel)
| Delivered energy     | ~14 kJ at 70% efficiency
| Cycle time           | ~25–30 s
| Reactor tube         | 18 mm ID × 21.6 mm OD quartz (Wale CFQ18X21.6)
| Discharge switch     | WESTCODE N170CH12 W8 puck
| Charging supply      | Lumina CCPF-1700-1.5P-SYS
| Electrodes           | Architecture 4: graphite puck + Cu push rod
| Atmosphere           | Argon flush / 7.6 Torr / 10 mTorr
| Estimated build cost | $4,800–8,300
|===

== Reading order

For someone picking this up cold:

. Read this README
. Skim `spec/00_overview.adoc` for purpose and architecture
. Open `data/bom.csv` (renders nicely on GitHub) for sourcing state
. Open `data/pending.yaml` for the open work list
. Dive into specific subsystem files in `spec/` as needed

== Conventions

* *LOCKED* in spec text: decision is final and should not be revisited without explicit reason
* *[GAP-FILL]* in section headings: content added during the 2026-05-10 gap-analysis pass
* Pending item ID prefixes: `VERIFY-*` (validation), `BENCH-*` (bench tests), `DESIGN-*` (open design), `GAP-*` (gap-fill), `ELECTRODE-*` (electrode design Q1–Q6), `FUTURE-*` (deferred), `RES-*` (resolved)

== Known confabulation history

Items caught during specification development, recorded to prevent regression. Full list in `spec/appendix.adoc`. Summary:

* "Coilcraft VPH4-0190" — *part does not exist*; correct part is *SD250-3L*
* 80 µs gate pulse width — saturates SD250-3L core; corrected to 25–40 µs
* "ChemGlass 4100N32" — not in ChemGlass catalog; actual source is *Wale Apparatus CFQ18X21.6*
* Cap-bank ESR figures — used unsourced values (~10 mΩ then ~24 mΩ per cap); correct value is *13 mΩ at 100 Hz, 20 °C* per Kemet datasheet → bank ESR 0.93 mΩ for 14 caps in parallel
