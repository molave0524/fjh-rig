=== Gate driver

[source]
----
ESP32 GPIO → opto-isolated MOSFET → Coilcraft SD250-3L → SCR gate
----

[cols="2,3", options="header"]
|===
| Parameter | Value

| Gate pulse amplitude | 5–10 V peak, 1–1.5 A
| Rise time            | <1 µs
| Pulse width          | ~25–40 µs (hardware timer; *not* 80 µs — saturates SD250-3L)
| Snubber              | R-C across SCR
| Gate routing         | Twisted pair, away from bus bar
|===

NOTE: Earlier specs referenced "Coilcraft VPH4-0190" — *this part does not exist*. Correct part is *SD250-3L*. Earlier specs also called for 80 µs gate width — this saturates the SD250-3L core; corrected to 25–40 µs.
