== Abstract

Bench-scale Flash Joule Heating (FJH) rig for converting 1 g of carbonaceous feedstock per shot (carbon black, calcined coke, biochar) into turbostratic flash graphene. Headline: 14-cap bank @ 252 mF / 400 V delivers ~14 kJ per shot; ~30 s cycle time; argon-flush or vacuum atmosphere; 18 mm ID quartz reactor.

NOTE: This document is a *working specification*. Treat any specific number as a starting point for verification, not a guarantee.
